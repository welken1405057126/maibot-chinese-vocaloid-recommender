# MaiBot 中文 Vocaloid 推荐插件

在 QQ 群中收录和推荐中文 Vocaloid B 站投稿。项目目前处于 `0.1.0` 开发阶段，上传和图文随机推荐已经完成，删除命令仍在接线。

## 当前进度

- [x] `/中v帮助` 命令
- [x] SQLite 曲库、重复判断、随机查询和软删除底层
- [x] BV/AV/b23.tv 链接检查与 B 站视频信息读取
- [x] 请求超时、响应大小限制和链接白名单
- [x] 封面下载、文件头校验、本地缓存和容量清理
- [x] `/上传中v` 接入曲库、三级限流与封面缓存
- [x] `/中v推荐`、`/随机中v` 接入随机查询、近期排除和纯文本发送
- [x] 推荐命令接入封面、元数据按需刷新、按聊天流冷却和纯文本降级
- [ ] `/中v删除` 接入上传者、群管理员和全局管理员权限

## 环境要求

- Python 3.12 或更高版本
- MaiBot 1.0.0 至 1.0.11
- MaiBot Plugin SDK 2.x
- 不需要单独安装数据库或服务器；曲库使用 Python 自带的 SQLite
- 不需要额外安装 `aiohttp`；MaiBot 已将其作为核心依赖

## 配置

复制 `config.example.toml` 为 `config.toml`，再按文件内注释填写。`config.toml` 包含群号和管理员 QQ 号，已被 Git 忽略，不应提交到公开仓库。

重要规则：

- `allowed_group_ids = []` 表示不限制群；试运行时建议只填写测试群号。
- `global_admin_ids = []` 表示没有额外的全局管理员。
- `library_mode = "global"` 表示所有群共享同一个曲库。
- B 站接口地址和请求头由代码固定，配置中只能调整超时、短链跳转次数和响应大小上限。
- 封面缓存默认上限为 256 MiB，超过后优先清理孤儿和软删除曲目的文件。
- 曲库和封面位于 MaiBot 的 `data/plugins/welken.Chinese_vocaloid_recommender/`，不在插件 Git 仓库内。
- 推荐默认避开当前聊天最近 5 首，同一聊天流有 5 秒冷却；元数据默认超过 2 天才向 B 站刷新。

## 命令

| 命令 | 权限 | 状态 | 说明 |
| --- | --- | --- | --- |
| `/中v帮助` | 所有人 | 可用 | 显示命令说明 |
| `/中v推荐`、`/随机中v` | 所有人 | 可用 | 图文推荐一首中文 Vocaloid，封面失败时自动退化为标题和链接 |
| `/上传中v <B站链接>` | 所有人，受频率限制 | 可用 | 收录 BV、AV 或 b23.tv 视频链接 |
| `/中v删除 <ID>` | 上传者、来源群管理员或全局管理员 | 开发中 | 软删除指定曲目 |

所有命令必须以半角 `/` 开头。当前没有“按 ID 推荐”命令；数字 ID 仅用于删除和内部审计。

## 开发检查

在插件目录依次运行：

```powershell
python -m compileall -q .
..\..\.venv\Scripts\python.exe -m ruff check .
python -m unittest discover -s tests -v
git diff --check
```

语法检查只能证明文件可解析；Ruff 检查未定义名称和明显错误；自动测试验证实际行为及旧功能回归。自动测试不访问真实 B 站，网络响应和短链跳转均使用本地模拟。
